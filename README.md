# Lampa Main Genre Filter

A small plugin for Lampa that hides movies whose primary genre is on a user-defined blacklist. If you are tired of endless horror results and the same ugly cover art appearing in every section of the catalog, this plugin helps keep the feed a little more bearable.

I got fed up with seeing horror in the recommendations, horror in the lists, and horror everywhere else on the screen. Since that genre is not remotely interesting to me, I decided to build a tiny filter that removes those cards from all pages as soon as the main genre matches a blocked entry.

The plugin checks the first available genre from the item payload, compares it against a curated preset list and any custom TMDB genre IDs you add manually, and hides the matching titles before they render. Horror is enabled by default because apparently the universe decided that the first thing everyone wants to see is a cursed clown in a basement.

## Features

- Hide a main genre across all result pages
- Built-in curated blacklist presets
- Optional manual TMDB genre ID overrides
- Works by filtering results before they are displayed
- Lightweight and easy to tweak

## Installation

1. Copy `lampa-main-genre-filter.js` into your Lampa plugin or custom script folder.
2. Load it in your Lampa setup.
3. Open the settings and enable or disable the blocked genres as needed.
4. Add extra TMDB genre IDs in the manual field if you want to block more than the default preset list.
